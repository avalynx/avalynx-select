## Release 1.2.3 – Changelog Summary

Feature and maintenance release that makes AvalynxSelect usable inside hidden containers such as Bootstrap modals, and refreshes the development tooling.

* **Modal Support (Dropdown Width Recalculation)**
  AvalynxSelect now recalculates the dropdown width when it is opened, in addition to the existing window-resize handler.
  Components initialized inside a hidden container (e.g. a closed Bootstrap modal) previously kept the stale `0px` width measured at init time; the dropdown now sizes correctly on first open (`show.bs.dropdown`).
  Demonstrated by the new example `examples/simple-select-modal.html`.
* **Development Environment Simplification**
  Common Docker Compose tasks are centralised in a `core.sh` script; HTTP/HTTPS ports and the project name are configured via environment variables.
  Example pages now default to English.
* **Version Bump Across Assets**
  Updated distributed files, headers, package metadata, and CDN snippets to 1.2.3.
  Keeps npm, jsDelivr, and Packagist references in lockstep with the new tag.

**Compatibility**: Backward compatible
