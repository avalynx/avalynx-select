## Release 1.2.4 – Changelog Summary

Bugfix release that makes the dropdown width in hidden containers such as Bootstrap modals fully reliable.

* **Reliable Dropdown Width in Modals (ResizeObserver)**
  The dropdown width is now kept in sync with the select button via a `ResizeObserver` on the button element.
  Previously the width was only recalculated on `show.bs.dropdown` and window resize. When the dropdown was opened
  while the modal was still fading in, the width was measured as `0px` and the menu fell back to Bootstrap's
  narrow `min-width`, visibly smaller than the select button. In addition, `0px` is no longer written as a width,
  so a hidden state can never poison the dropdown size.
* **Version Bump Across Assets**
  Updated distributed files, headers, package metadata, and CDN snippets to 1.2.4.
  Keeps npm, jsDelivr, and Packagist references in lockstep with the new tag.

**Compatibility**: Backward compatible
