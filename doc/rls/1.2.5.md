## Release 1.2.5 – Changelog Summary

Feature release that adds flexible AJAX response handling: AvalynxSelect can now consume plain-text option lists in addition to JSON responses.

* **New `ajax.responseType` Option**
  The AJAX data source now accepts a `responseType` option (`'json'` (default) or `'text'`).
  With `'text'`, the response is parsed as plain text where each non-empty line becomes an option.
  Use `value|Text` per line to define a custom value; otherwise the line itself is used as both value and text.
  Enables integration with simple server endpoints that cannot return JSON.
* **Works with `mapResponse` and Live Search**
  Custom `mapResponse` callbacks receive the parsed response (`string` for `'text'`, `object` for `'json'`).
  Both the initial fetch and the live search pipeline fully support the new response format.
* **New Plain-Text AJAX Example**
  Added `examples/php/result-text.get.php` and a plain-text AJAX example demonstrating `responseType: 'text'`.
  Makes it easy to try the new behavior locally.
* **Docs & Version Bump Across Assets**
  README and README.de updated with the new option and example.
  Distributed files, headers, package metadata, and CDN snippets bumped to 1.2.5.
  Keeps npm, jsDelivr, and Packagist references in lockstep with the new tag.

**Compatibility**: Backward compatible — existing JSON integrations continue to work unchanged.
