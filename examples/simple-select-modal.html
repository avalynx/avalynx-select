This example demonstrates AvalynxSelect inside a Bootstrap modal. The selects are initialized on page load, while the modal is still hidden. When the dropdown is opened, its width is recalculated (via the show.bs.dropdown event), so it always matches the width of the select button.
AvalynxSelect in modal

Source of exampleCopy to clipboard

document.addEventListener('DOMContentLoaded', () => {
    new AvalynxSelect('#modal-select');
    new AvalynxSelect('#modal-select-livesearch', { liveSearch: true });
});
